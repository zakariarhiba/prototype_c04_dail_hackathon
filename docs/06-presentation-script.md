# Presentation Script

Not started. Fill in once there's a demo to show. Target: 3 minutes.

## Structure

1. Show the result first — one screen, the outcome, before explaining anything.
2. State the pain, in the client's words.
3. Walk the ordinary path, then the failure/uncertain path.
4. Say plainly: what works, what is simulated, what you learned (or assumed,
   per `02-client-interview.md`), and the next real case you'd test.

## Timing draft

| Time | Beat |
|---|---|
| 0:00–0:20 | Show the result |
| 0:20–0:50 | The pain |
| 0:50–2:00 | Demo: ordinary path + ambiguous/failure path |
| 2:00–2:40 | Real vs. simulated, honestly |
| 2:40–3:00 | Next validation test / handoff |
