# Phase 6 — 3-Minute Presentation Script

Show the result FIRST. State plainly what's demonstrated vs. what's a hypothesis.

## Timing budget (3:00 total)

**0:00–0:30 — Show the result first**
Open straight on the working demo / evidence view, not a slide.

**0:30–1:15 — The problem, in the client's language**
The pain: can't tell shortage vs. damage vs. duplicate scan vs. second delivery.
Why it's costly. What evidence you gathered from the "client" interview.

**1:15–2:30 — Demo walkthrough**
Ordinary path → changed-information event (trigger the simulate button) →
failure/uncertain case handed to a human.

**2:30–2:50 — What's real vs. simulated**
Name each component plainly (from the Implementation Status table).

**2:50–3:00 — Close**
What you learned from the client, and the next real case you'd test.
